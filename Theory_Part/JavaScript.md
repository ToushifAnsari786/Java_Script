JAVASCRIPT

1. JavaScript provides functionality to web pages.
2. It converts a static web page into a dynamic web page.
3. The founder of JavaScript was Brendan Eich. JavaScript was created in 1995 at Netscape.
4. In 1997, Netscape submitted JavaScript to ECMA
   (European Computer Manufacturers Association) for standardization.
5. The current standard is ECMAScript. ES6 was released in 2015.
   ES stands for ECMAScript.


FEATURES OF JAVASCRIPT

1. JavaScript is a scripting language.
2. JavaScript is used to design the frontend of an application.
3. JavaScript can be used as a client-side programming language.
4. JavaScript can also be used to develop the backend of an application.
5. With Node.js, JavaScript can be used as a server-side programming language.
6. JavaScript is a platform-independent language.
7. JavaScript code can be written on one operating system and can run
   on another operating system, provided the required JavaScript
   runtime/environment is available.
8. JavaScript follows the WORA principle:
   WORA = Write Once, Run Anywhere.
